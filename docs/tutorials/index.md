# Tutorials

- [Azure DevOps](./azure-devops.md) - scaffold the project, repos, feed, and pipelines; grant the build-service permissions
- [GitHub Actions](./github-actions.md) - cross-repo composite actions, GitHub Packages feed, and tag-pinned consumption
